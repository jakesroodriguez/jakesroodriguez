<br/>

```yaml

  renderer: "WebGLRenderer with antialias, ACESFilmicToneMapping & sRGBEncoding"
```

Nuestras experiencias 3D se diseñan desde cero para optimizar el **Draw Call Budget**. Agrupamos geometrías con *InstancedMesh*, gestionamos luces dinámicas sin saturar la GPU y aseguramos que cada modelo cargue de forma asíncrona mediante preloading inteligente.

</details>

<summary><strong>🎬 [EXPAND] 02 // CINEMÁTICA DE SCROLL & INTERACCIÓN FLUIDA (GSAP + Lenis)</strong></summary>

<br/>

```yaml
scroll_mechanics:
  scroll_driver: "Lenis Smooth Scroll with customizable inertia lerp (0.1)"

```

El scroll deja de ser un simple desplazamiento vertical: se convierte en el gatillo de una narrativa audiovisual interactiva donde el usuario tiene el control total de la velocidad y revelación de contenidos.
